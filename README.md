## 🔬 研究方向

主要研究**情绪与注意的认知交互**，重点关注**分心物抑制的时间动态过程**，综合运用行为学、脑电（EEG）和眼动追踪（Eye-tracking）等多模态实验技术，系统探讨注意加工的神经与认知机制。

**核心议题：**
- 威胁性刺激的注意捕获与抑制
- 应激状态下的注意选择机制
- 统计规则学习驱动的注意抑制
- ERP 成分（N2pc、PD）的认知解读
